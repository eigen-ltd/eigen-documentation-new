The header and footer remain visible on all pages. The header runs across the top of the interface while the footer runs along the bottom. Depending on your configuration, they may contain any combination of the following components:

:::note
If your configuration has a sidebar navigation style you may have some of these components on the sidebar instead.
:::

## logo

Displays the Eigen and/or customer logo, identifying the application and the organisation it is deployed for.

## Info button

Opens an overlay explaining the status colour codes in use for your deployment. As colour schemes can vary between configurations, this button provides a quick reference for what each colour and shade represents in your specific installation. If you are unsure what a status colour means, this is the first place to check.

##	Help button

Often indicated by a question mark icon. Opens contextual help or links to supporting documentation for the current page.

## Sign Out

When signed in, it will display your email as your username.

To sign out click the sign out / log out button. This will sometimes be under your profile.

##	Last time updated

Refresh the “Last Time Updated” to get an accurate timeframe.

Status will show the last time updated in the format: Day Month Year 00:00:00 Time zone [status]

##	Live data toggle

By default, the interface operates in Live Mode, meaning it is continually updated from data sources to reflect the most recent status.

It is possible to disconnect the live view and select a specific date in the past to see exactly what the barrier status was at that point in time.

##	Version

States which BSP version you are currently using (e.g. BSP-v1.20)

##	Print

Print the page.
