## How to navigate to the common menu

Right Clicking on impaired SECEs, barriers, or criticalities launches the Common Menu. (In some BSP configurations it may be triggered with a left click). 

![Trend Charts](~/assets/bsp/common-menu/image1.png)

This unique menu shows additional information about the reason for the impairment and provides direct links to the source data in other systems, such as maintenance records or risk assessments.

## Features of the Common Menu

***Add multiple Barriers to the common menu to compare.***

To add multiple barriers to the common menu, repeat the same action of adding to common menu on different barriers.

![Trend Charts](~/assets/bsp/common-menu/image7.png)

Easily switch between them by clicking on the barrier tabs.

![Trend Charts](~/assets/bsp/common-menu/image8.png)

To remove a barrier from the menu, press the x in the corner.

![Trend Charts](~/assets/bsp/common-menu/image9.png)

Move common menu anywhere on the screen using the drag button.

![Trend Charts](~/assets/bsp/common-menu/image10.png)

When you are finished with the common menu you can close it by clicking the x in the corner.

![Trend Charts](~/assets/bsp/common-menu/image2.png)

:::caution[Warning]

If you close the common menu, it will reset back to default. So, make sure you’ve finished viewing/comparing the barriers before you close them.

:::
