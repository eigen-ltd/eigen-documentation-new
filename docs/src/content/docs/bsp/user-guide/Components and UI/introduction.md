As each BSP deployment is configured to the specific needs of the facility it represents, the components visible in your interface may differ from those described in this section. Not every component listed here will be present in every deployment, and the arrangement of components on the page may vary.

The sections below describe all possible interface components across all known BSP configurations. If a component described here is not visible in your deployment, it has not been included in your configuration. If you believe a component should be present but is not, please contact Eigen for clarification:

Email: info@eigen.co
Web: eigen.co
