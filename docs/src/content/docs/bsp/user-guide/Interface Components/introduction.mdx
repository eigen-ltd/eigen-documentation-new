Interface components are different ways of displaying data, for example charts, tables, sunbursts. Different pages may have a different combination of interface components, but the components themselves will typically present the same type of data. 

This section will explain each component, how it is typically presented in the BSP (it may look different depending on your configuration) and worked examples of how to understand each component so that they can support your day-to-day tasks.

Types of interface components:

-	Tables
-	KPIs
-	Traffic Lights
-	Lists
-	Hierarchies
-	Rag Matricies
-	Visual Diagram
-	Bubble Chart
-	Sunburst
-	Standard Charts
-	Bowtie Visualisation.
