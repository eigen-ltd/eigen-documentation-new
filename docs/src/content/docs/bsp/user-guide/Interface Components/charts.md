Depending on your Eigen BSP configuration, the features and UI of charts will vary. More recent BSP instances follow very similar chart features and UI as Ingenuity 7. If you are familiar with Ingenuity charting, much of what you know will transfer directly to the BSP.
[See Ingenuity Charts Section.](https://docs.eigeningenuity.co/modules/charts/overview/)

However, there are some key differences between BSP charting and Ingenuity charting. 

![Asset Overview](~/assets/bsp/components/image28.png)

**Similarities with Ingenuity**

- **Trending from basket:** You can add items to your basket and create trends from them. The process of selecting items and building a chart from your basket works the same way as in Ingenuity.
- **Adding tags:** The process for adding tags to a chart is the same as in Ingenuity. You select the tags you want to trend and they are added to the chart display.
- **User interface:** In newer BSP instances, the UI for charts closely matches Ingenuity. Navigation, controls, and interaction patterns will feel familiar.
- **Real-time trending:** Charts update in real time as new data is received, allowing you to monitor trends as they develop.

**Differences from Ingenuity**

- **No ad-hoc calculations:** Unlike Ingenuity, the BSP does not support ad-hoc calculations or on-the-fly formula creation within charts. All calculations and business rules are pre-defined and recursive. If you need a trend that is not currently available, this would need to be configured by your organisation's administrators rather than created on demand.
- **On-demand trending:** On-demand chart creation — where you can create a new chart for any data at any time — is an Ingenuity feature. The BSP charts are pre-configured and deployed as part of your system setup.
- **No chart widgets:** The BSP does not have a separate chart widget that you add to pages. Charts are pre-configured and appear on your pages as your organisation has set them up during deployment. You cannot add or remove charts yourself in the way you might in Ingenuity.
