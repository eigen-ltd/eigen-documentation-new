##	Lists

Lists are one of the ways data is displayed in the BSP. Unlike tables, which present detailed tabular data with multiple columns and sorting options, lists provide a simpler, more scannable format suited to summarizing categories of information at a glance.

Lists are typically used in the Major Accident Hazard section, where they are used to display the different types of work orders associated with a specific hazard. Each item in a list will usually be accompanied by a title and an icon, making it easy to identify the type of information being presented without needing to read in detail.

Lists may also act as navigation cards so if you click on them you will be redirected to another location. 

![Status Tables](~/assets/bsp/components/image11.png)

:::note
You cannot filter or sort data displayed in a list.
:::
