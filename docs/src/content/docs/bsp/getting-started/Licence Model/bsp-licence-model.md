The Eigen Barrier Status Panel (BSP) is an online web application for visualising the current health of safety barriers in industrial assets that connects to all sources of barrier impairment and risk indicators to provide a unified picture of barrier health status and risk, in compliance with Norwegian, European and UK regulations. 
It is deployed as containers in a cloud computing environment with connectivity to the data sources that contain the information that will be used to calculate barrier health status.

## Barrier Status Panel licencing model

The Eigen Barrier Status Panel (BSP) licence model is structured around three components:
- Asset licences;
- Ruleset support fees
- Application Instance support fees; and
- Connector support fees

|||
|---|---|
|**Component**	|**Pricing Structure**|
|Asset Licence	|£ X Per asset (up to 50 assets). Enterprise pricing above 50 assets, no additional asset fees.|
|Application Instance Support Fee	|£ Z per instance|
|Ruleset Support Fee |£ Y per Ruleset. Per additional assets with the same Ruleset: £0.1 x Y. Over 50 rulesets: £0.1 x Y per ruleset|

***Base prices £X, £Y and £Z are updated every year based on inflation and are exclusive of VAT and any other applicable taxes.***

An **"Asset"** refers to a distinct physical facility, site, or operational unit that a business manages under a common Barrier Management structure.

A **"Ruleset"** is the comprehensive collection of logic and rules that defines how source data is collected, interpreted, and processed to calculate the status of each element within a Barrier Model for a specific Asset. 

An **"Instance"** is a physical installation of the Eigen BSP application deployed on the customer's infrastructure. Each Instance operates with a distinct URL and represents a separate deployment environment. An Instance licences is only required for the Production (PROD) system and covers  for development (DEV) or TEST instances installed to support typical Management of Change processes.

## Designed to support scaling

The licence model is structured to support extending the BSP across a portfolio. The first deployment of an Application Instance and Ruleset bears the bulk of the cost — which is appropriate, because that is where the implementation work sits: integrating the source systems, calibrating the rules, and validating the barrier model against the operator's standards. 

Once that foundation is in place, each additional Asset added to the same Instance and Ruleset attracts only its Asset Licence plus a Ruleset top-up of 10% of the first-deployment fee, with no additional Instance fee at all. Asset fees are also capped under Enterprise pricing above 50 assets. The effect is a steep fall in the average per-asset cost as coverage expands.
