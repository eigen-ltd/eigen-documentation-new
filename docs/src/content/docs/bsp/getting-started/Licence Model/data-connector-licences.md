## Data connector licences

Each instance of the BSP includes 1 data connector licence.  Additional data connectors are licenced according to connector type (see example in the table below). Data connector licence fees include Support and Maintenance.

|||
|---|---|
|**Connector type**	|**Pricing Structure**|
|Data Lake	|Azure, DataBricks, AWS, Cognite, DreamFactory, Snowflake etc|
|SDK/API (to single system)	|Synergi, SAP, Documentum, PIMS|
|Write back	|Connector to write back data to a database or data lake, such as Barrier Status|

See current list of available connectors.
