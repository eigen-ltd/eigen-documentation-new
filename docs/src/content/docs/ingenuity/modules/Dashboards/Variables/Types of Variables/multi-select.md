The Select type variable lets a user select multiple options from a pre-defined list. These are typed as a comma-separated list in the “Possible values” field.  

>For example, Aa, Bb, Cc

![Trend Charts](~/assets/dashboards/variables/image1.png)

To show a more user friendly name to the user, labels can be defined in square brackets before each variable:

>[Label 1]Aa,[Label 2]Bb

![Trend Charts](~/assets/dashboards/variables/image2.png)
