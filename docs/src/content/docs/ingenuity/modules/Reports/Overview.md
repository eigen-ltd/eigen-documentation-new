### 1.1	What are the Reports

The Reports is a standard module in Ingenuity which enables users to:

- Create, schedule and distribute reports. 
- Turn any dashboard or a Logbook instance into a report.
- Issue reports via email.
- Create versions of a report for different audiences.
- Retain the history of issued reports in the static format.
- Search and retrieve past reports.

It is accessed via the “Reports” entry in the left-hand panel.

![Reports button in Ingenuity](~/assets/reports/image1.png)

The Reports lets the user to manage and trigger the existing reports or create new reports.
