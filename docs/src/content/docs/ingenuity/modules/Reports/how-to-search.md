## 2 How to search issued reports

### 2.1 Global Search

[Not exist] Start typing the name of the report you would like access. 

![Search function in Ingenuity](~/assets/reports/image3.png)

### 2.2	Drill down to Issued Reports

Go to ‘Reports’ and click a desired report

![Button for a report](~/assets/reports/image4.png)


Within the report definition detail click ‘View issued reports’

![View issued reports](~/assets/reports/image5.png)


The list of ‘Issued reports’ is presented. Click on a desired issued report to view

![List of issued reports](~/assets/reports/image6.png)
