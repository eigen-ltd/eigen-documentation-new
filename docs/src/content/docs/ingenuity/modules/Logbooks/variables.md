### Add variable

Once in the edit variables section, Click Add Variable

![Trend Charts](~/assets/logbooks/image106.png)

This will show a list of existing variables (if any). 

![Trend Charts](~/assets/logbooks/image107.png)

Click the dropdown to reveal the fields to fill in.

:::note
To edit an existing variable click the dropdown to reveal the fields to fill in. edit the relevant fields and press Save
:::

![Trend Charts](~/assets/logbooks/image108.png)

***Name***

Name your variable

***Type***

Choose a variable type – default will be select.

- Select
- Multi select
- String
- Number
- Boolean
- Date
- Filter
- Select from Datasource output
- Value from Datasource output
- User
- Conditional

Refer to [Variables section](/ingenuity/modules/dashboards/variables/setting-up/) for more information on variable types.

![Trend Charts](~/assets/logbooks/image109.png)
