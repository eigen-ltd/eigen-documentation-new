### What is the Time Select field?

The ‘Time-based Value’ enables users to enter the timestamp data format entry into a Logbook record. 

![Trend Charts](~/assets/logbooks/image95.png)

:::note
This is not the same as the Logbook record timestamp.
:::

![Trend Charts](~/assets/logbooks/image96.png)

To configure the selection, fill in the additional ‘Options’ field:

***Options***

Press Add Option to create new entry.  

:::note 
When adding a new entry, from default value will be 01:00
:::

![Trend Charts](~/assets/logbooks/image97.png)

Add Label and time range (format: 00:00). 

![Trend Charts](~/assets/logbooks/image98.png)

To remove an option press Remove
