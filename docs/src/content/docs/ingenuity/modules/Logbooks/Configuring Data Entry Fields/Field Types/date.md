### What is the Date field?

The ‘Date’ field enables users to input date entry into the Logbook record. 

![Trend Charts](~/assets/logbooks/image92.png)

### How is this displayed in the add entry form?

Choose a date and time.

![Trend Charts](~/assets/logbooks/image93.png)

> This will be in the format DD/MM/YYYY 00:00

![Trend Charts](~/assets/logbooks/image94.png)
