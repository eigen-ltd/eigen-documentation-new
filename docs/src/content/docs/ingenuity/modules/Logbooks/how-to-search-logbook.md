## 2.1 Standard Filters

![Trend Charts](~/assets/logbooks/image15.png)

#### Author

![Trend Charts](~/assets/logbooks/image16.png)

From the dropdown menu select one or more authors. An author is an Ingenuity user who has permission to a Logbook module. When selected, only records created by a selected author(s) will be displayed.

![Trend Charts](~/assets/logbooks/image17.png)

#### Tag

![Trend Charts](~/assets/logbooks/image18.png)

From the dropdown menu select one or more of the tags created by users while creating a Logbook entry. Tags group the content by user-defined label and are not preconfigured.

![Trend Charts](~/assets/logbooks/image19.png)

#### Date/Time Range Picker

![Trend Charts](~/assets/logbooks/image20.png)

Default time range is one year back from today.
Daytime range selection consists of start day-time -> end date/time. The date and time are picked using the calendar widget.  Click the first entry to pick the start of the time filter range. Click the second entry to pick the end of the time filter range.

![Trend Charts](~/assets/logbooks/image21.png)

#### Time Range Selection

![Trend Charts](~/assets/logbooks/image22.png)

From the predefined list of time ranges select one of the entries.

![Trend Charts](~/assets/logbooks/image23.png)

#### Reset Filters

Resets all the user-selected filters to their default values.

## 2.2	Search

Search in Logbook enables users to find records that match the search criteria within the logbook entry Comments.

![Trend Charts](~/assets/logbooks/image26.png)

## 2.3	Navigation

By default, a Logbook displays only first 50 entries (rows) per page. To increase number of entries visible entries, select one of the values from the View dropdown list.

![Trend Charts](~/assets/logbooks/image54.png)

If there a more records that pass the filter criteria and the selected number of rows, click Next and Previous buttons to navigate between pages.

![Trend Charts](~/assets/logbooks/image55.png)
