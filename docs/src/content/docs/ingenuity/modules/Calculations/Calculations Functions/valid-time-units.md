## 2.3 Valid Time Units

Many of the calculation functions accept units of time input. The
following are valid in all cases:

> s: seconds
>
> m: minutes
>
> h: hours
>
> d: days
>
> w: week
>
> mo: months
>
> y: year

#### *For example:*

|  |  |
|-----------:|:------------|
| 1 second: | `1s` |
| 1 minute: | `1m or 60s` |
| 7 days: | `7d or 1w` |
| 1 calendar month: | `1mo` |
| 6 hours: | `6h` |
